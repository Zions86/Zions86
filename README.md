# Story Teller — Starter Scaffold

This repository contains the Story Teller starter scaffold generated by GitHub Copilot.

Overview
- Frontend: Next.js + TypeScript + Tailwind
- Backend: Express + TypeScript + Prisma (PostgreSQL)
- AI: OpenAI integration stubs
- Image storage: Cloudinary (configurable)
- Actor Finder: TMDb (stubs)

Quick start (development)
1. Copy `.env.example` to `.env` and fill in required secrets.
2. Start services with Docker Compose:
   docker-compose -f docker/docker-compose.yml up --build
3. From the backend package folder:
   npm install
   npx prisma generate
   npx prisma migrate dev --name init
   npm run dev
4. From the frontend package folder:
   npm install
   npm run dev

See docs/ for more details.
